# Security Policy

## Reporting a vulnerability

Do not open a public issue or discussion for a suspected vulnerability. Use GitHub's
[private vulnerability reporting form](https://github.com/fabriciorostand/summyz-community/security/advisories/new)
so the report and follow-up remain private while maintainers assess and address it.

Include the affected revision or version, environment, expected impact, reproduction
steps, and any known mitigations. Use synthetic examples: do not attach real tokens,
credentials, raw audio, transcripts, or other private meeting content.

Maintainers will review the report through the private security advisory and coordinate
responsible disclosure there. Please do not publish the vulnerability before that
coordination is complete.

For ordinary bugs and feature requests, use the public
[issue tracker](https://github.com/fabriciorostand/summyz-community/issues).
